# 按领域选择的口径检查

这些是候选检查视角，不是必须逐条覆盖的清单。只采用题干、数据和评测目标支持的内容；先核实具体材料，不凭领域名称预设结论。没有对应领域的题目，直接用 `SKILL.md` 的通用规则，不必强行套用某一节。

## 半导体

- 比较器件性能前，检查器件类型、几何尺寸、温度、偏置、频率、测试方法和样本规模是否一致；不一致时判断可比范围。
- 区分原始测量值与按面积、宽度或其他基准归一化后的量；追踪分母和单位，避免不同基准的数值直接排序。
- 提取图表数据时记录坐标轴、线性或对数刻度、图例、拟合范围和读取误差；图中近似值不作为无容差的精确真值。
- 对模型、近似公式和拟合结果检查适用区间；只有题目需要时评测寄生项、接触影响或其他修正，不能默认必须采用某一修正模型。
- 比较模拟、实验、典型值和极值时保留各自性质；结论要受工作条件及证据强度约束。
- 多变量同时改变时（如温度与栅压），先判定贡献能否分离；不能分离就不得把差值归因于单一变量。

## 材料数据审查

- 冻结样品标识、批次、制备路线、处理历史、测试条件及组分基准；质量分数、原子分数和摩尔分数不能混用。
- 区分独立样品、技术重复和重复录入；统计样本数要与独立性一致。
- 对缺失值、检测限以下值、异常点和失效记录定义处理依据；不得无说明地置零、删除或插补。
- 处理汇总统计时确认均值、标准差、标准误和置信区间的含义；加权或汇总计算应使用匹配的样本数与定义。
- 检查总量、组分闭合、量纲和物理可行范围；不符合时追踪原始记录、转换或归一化环节，避免强行修正以满足预期。
- 比较数据库、附件表和正文时核对版本及记录映射；相互冲突时按题目规定裁决，未规定时保留冲突并限定结论。

## 科研测评

- 识别研究设计、比较对象、对照、重复、排除标准和预先指定的指标；分清探索性与验证性分析。
- 把效应大小、不确定性和统计显著性分开判定；不能仅以显著性替代实际效应或因果证据。
- 对涉及模型评估的题目检查数据划分、独立性、泄漏、基线、指标分母和阈值口径；只在材料支持时评测这些节点。
- 比较文献结论时区分研究条件及证据层级；原始结果、作者解释和模型推断分别追踪。
- 将可重复性绑定到实际所需参数、数据处理和计算步骤；不要笼统要求"可复现"而不给判据。

## 代码与 agent 任务

- 冻结运行环境：语言与版本、依赖、入口命令、输入形态、允许访问的资源。环境未冻结时，要求模型显式声明假设，而不是默认某个环境。
- 区分"现象"与"根因"：要求定位到具体位置（文件、函数、行或调用链）并给出触发条件；只描述症状不算定位。
- 最小修复的判据写成可静态核对的约束：改动范围、是否保持公开接口、是否引入新依赖、是否处理并发／重入／超时。
- 并发与状态问题要写清可观察的不变量（如计数器单调、锁覆盖区间、失败可重试）。只说"要注意线程安全"不可判。
- 对 agent 任务，检查工具调用是否必要、参数是否合法、失败后是否重试或降级、是否在无权限时停下并说明；把"正确停下"写成合格答案之一。
- 不把"运行测试通过"当唯一判据，除非评测流程真的执行；只判答卷里可核对的推理与代码文本。
- 安全边界单列：越权访问、破坏性操作（删除、覆盖、批量写入）、凭证处理、外部请求的副作用。触发即否决，依据见 `references/scoring.md` 第 5 节。

## 通用问答与长文

- 事实类：区分题干给定的事实、模型引入的外部事实、模型自身的推断；三者混写是主要失分点。引入外部事实时要求可核对的来源，没有来源就不得当作已确立的前提。
- 时效类：题干给出时间点或版本时，以该时点为界；模型未声明时点就使用"当前""最新"这类词，属口径未冻结，不得据此判分。
- 推理类：要求给出中间量与推理链，能复算；只报结论的正确答卷在过程条上应失分，蒙对与算对要区分开。
- 长文：把结构与内容分开判。结构判据（是否分节、是否先给结论、是否覆盖指定维度）要能数出来；内容判据绑定具体论据，不用"论证充分""逻辑严谨"。
- 引用类：区分"给了引用"与"引用支持该断言"。允许正确答案指出某条材料不支持或相互矛盾；指出冲突并限定结论的答卷应通过，不应因"没给出统一答案"失分。
- 不确定表达：要求模型标注置信度或不确定性时，写清判定条件（哪些部分确定、哪些是推测、推测对结论的影响），不接受一句"仅供参考"。

## 写法示例：将模糊要求改为可检查规则

以下仅展示写法，不是可直接复制的现成题目考点：

- 模糊：是否正确计算并深入分析结果。
- 改写结构：`1. 模型是否使用题目规定的样本集合与归一化分母，列出可复算的中间量，并以规定单位报告结果；数值误差满足根据输入精度确定的容差。` 真正交付时须替换为题目中的集合、分母、单位及具体容差。
- 模糊：是否识别异常值。
- 改写结构：`2. 模型是否依据题目给定的异常判据标记对应记录，说明该记录是否进入汇总计算及其依据，并报告处理对结果的影响；未触发判据时保留记录。` 真正交付时须指明判据及可核对结果。
- 模糊：是否交叉验证。
- 改写结构：`3. 模型是否用独立约束复核目标结果，并依据预设差异阈值判断一致性；超阈值时定位冲突来源并限定结论。` 真正交付时须写清独立约束、阈值来源和异常分支。
- 模糊：是否定位并修复了 bug。
- 改写结构：`4. 模型是否把缺陷定位到<文件:行或调用链>，说明触发条件（并发时序／输入形态），并给出不改变公开接口的最小改动；以题目给定的最小改动范围核对。` 真正交付时须写清位置判据与可接受改动边界。
- 模糊：回答是否可靠、有据。
- 改写结构：`5. 模型是否把关键断言绑定到<具体材料位置>，区分材料支持、材料不支持与材料未涉及三种情形，并对未涉及部分标注不确定性或不作断言。` 真正交付时须替换为实际材料与断言清单。
